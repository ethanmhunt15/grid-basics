Experiments

  1. Watch a rare state arrive. Reset Experiment 1 and run one trial repeatedly. What happens to the estimates when “neither available” first appears?
  2. Change only the seed. Run 100 system trials with several seeds, then repeat at 5,000. Which result is more stable, and why?
  3. Compare frequency and depth. Add 10 GW of flat load, then add flexibility. Do LOLE and EUE improve by the same proportion?
The annualized system results are outputs of a fictional teaching model, not estimates of current or future PJM reliability.
